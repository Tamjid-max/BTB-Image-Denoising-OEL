# Research Paper Reference

**Deborah Pereg**, "Back to basics: Fast denoising iterative algorithm," *Signal Processing*, vol. 221, 109482, 2024.

DOI: https://doi.org/10.1016/j.sigpro.2024.109482

## Reproduction note

The original natural-image experiment uses a pretrained TNRD denoiser inside the BTB framework. This student reproduction keeps the BTB iterative update but uses Non-Local Means (NLM) as the base denoiser for a lightweight and explainable Python implementation.

The publisher PDF is intentionally not redistributed in this public repository. Use the DOI above to access the original article through the publisher or your institution.
